# unofficial-grapheneos-boot-animation
This project was created due to the lack of boot animation **GrapheneOS** in open sources.
# Description
This project contains an executable file for generating boot animation, as well as an archive with generated boot animation with standard settings. There is also a logo that was used to generate sequential images. 
> You can also modify the parameters in the source code to adapt it to your device.

# Installation
```bash
git clone https://github.com/MichaelSemenov/unofficial-grapheneos-boot-animation.git
cd unofficial-grapheneos-boot-animation
python3 -m venv venv
source venv/bin/activate
pip3 install -r requirements.txt
python3 GrapheneOS-bootanimation.py
```
